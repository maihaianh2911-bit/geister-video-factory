Xưởng Duyệt Hình

Ba bước cho mỗi video: dán kịch bản, đưa hình mẫu hoặc prompt, rồi duyệt hình từng cảnh. Mọi thứ lưu thẳng vào GitHub của kênh.

— Mở phiếu

Kết nối GitHub (làm một lần)

  1. Mở trang tạo mã truy cập (đăng nhập GitHub nếu được hỏi).
  2. Token name: gõ xuong-duyet-hinh. Expiration: chọn 1 năm.
  3. Repository access: chọn Only select repositories → geister-video-factory.
  4. Permissions → Repository permissions: Contents = Read and write, Issues = Read and write.
  5. Bấm Generate token, chép mã (bắt đầu bằng github_pat_) rồi dán vào ô dưới.
Mã chỉ lưu trong trình duyệt này, không gửi đi đâu ngoài GitHub.

Kịch bản

Tiếng Việt hay tiếng Đức đều được. Claude viết lại cho cuốn hút, đổi tên người, địa danh, tiền sang kiểu Đức.

Hình mẫu

Thả ảnh mẫu (phong cách, nhân vật) hoặc tả bằng lời, hoặc cả hai. Mẫu chỉ áp cho video này.

3

Phê duyệt hình

Mỗi cảnh: bấm Duyệt nếu ưng, hoặc ghi góp ý rồi bấm Cần sửa.

Chưa có hình. Bấm “Gửi cho Claude vẽ” ở bước 2 rồi nhắn Claude trong chat. Hình từng cảnh sẽ hiện ở đây.
